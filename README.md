# QalbPlayer Full Test App

This is a Next.js App Router test app for `qalbplayer@1.0.2`.

It includes pages for:

- `/` Home test dashboard
- `/video` YouTube-style long video
- `/shorts` YouTube Shorts style vertical player
- `/reels` Instagram Reels style vertical feed
- `/live` Live stream mode

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Render

Build Command:

```bash
npm install && npm run build
```

Start Command:

```bash
npm start
```
